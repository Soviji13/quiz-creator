# Install the plugin

To use this plugin, you'll need to meet the following requirements:

## 1. Download Obsidian

If you don't have Obsidian yet, you can visit the [official website](https://obsidian.md) of Obsidian and download the plugin from there.

## 2. Add the plugin

> [!note] Note for version 1.0.0:
> The plugin isn't on the Obsidian Plugins MarketPlace yet because they're temporarily not accepting PRs. Therefore, the current plugin download method is temporary, through [BRAT](https://community.obsidian.md/plugins/obsidian42-brat).

Once you have Obsidian downloaded:

1. If you've never used a community plugin before, go to: **Settings** &rarr; **Community plugins** &rarr; select **Turn off restricted mode**

2. Install the BRAT plugin. You can do this through the [website](https://community.obsidian.md/plugins/obsidian42-brat) or through **Community plugins** &rarr; **Community plugins** &rarr; select **Browse**.

3. Once you have BRAT installed, access its settings through **Community plugins** &rarr; click the three dots to the right of BRAT &rarr; **Settings** &rarr;

![Image of step 3](/images/step3_getting_started.png)

4. In settings, click the + to the right of `Beta plugin list`

![Image of step 4](/images/step4_getting_started.png)

5. Paste `https://github.com/Soviji13/quiz-creator` into the input field, wait a moment until the border turns green, and select **Add Plugin**. Don't touch anything else.

![Image of step 5](/images/step5_getting_started.png)

Done! You now have the plugin installed.
