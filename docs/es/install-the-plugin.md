# Instalar el plugin

Para poder utilizar este plugin, necesitarás cumplir los siguientes requisitos:

## 1. Descargar Obsidian

Si aún no tienes Obsidian, puedes visitar el [sitio web oficial](https://obsidian.md) de Obsidian y descargar el plugin desde ahí.

## 2. Añadir el plugin

> [!note] Nota para versión 1.0.0:
> El plugin aún no se encuentra en el MarketPlace de Plugins de Obsidian debido a que temporalmente no aceptan PRs. Por tanto, el método de descarga del plugin actual es temporal, a través de [BRAT](https://community.obsidian.md/plugins/obsidian42-brat).

Una vez tengas descargado obsidian:

1. Si nunca has utilizado un plugin comunitario, ve a: `Ajustes` &rarr; `Complementos comunitarios` &rarr; clic en `Salir del modo restirngido`

2. Instala el Plugin BRAT. Puedes hacerlo a través de la [web](https://community.obsidian.md/plugins/obsidian42-brat) o a través del apartado `Complementos comunitarios` &rarr; `Complementos creados por la comunidad` &rarr; clic en `buscar`.

3. Una vez tengas instalado BRAT, accede a sus ajustes a través de `Complementos comunitarios` &rarr; Pulsar sobre los tres puntos a la derecha de BRAT &rarr; `Ajustes` &rarr; 

![!Imagen del paso 3](/images/step3_getting_started.png)

4. En ajustes, haz click sobre el + a la derecha de `Beta plugin list`

![Imagen del paso 4](/images/step4_getting_started.png)

5. Pega `https://github.com/Soviji13/quiz-creator` en el input que sale, espera un momento hasta que se ponga el borde verde y pulsa sobre `Add Plugin`. No toques nada más.

![Imagen del paso 5](/images/step5_getting_started.png)

¡Listo! Ya tienes el plugin instalado.
